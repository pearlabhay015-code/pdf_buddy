# PDF Buddy 📄✨

A friendly, modern, borderless app to convert screenshots and images into PDFs.

## Highlights
- **100% Vector Brand Logo**: "PDF Buddy" scalable vector logo in crisp sky blue and white.
- **Single-Place Paste Canvas**: Press <kbd>Ctrl + V</kbd> anywhere to paste screenshots, or click to browse files.
- **Add More Images Anytime**: Add more images whenever you want via the top button or the interactive grid card.
- **Image Adjustments & Resize**: Fine-tune dimensions/scale, brightness, sharpness, and saturation per page or across all pages.
- **Icon-Only Actions**: Clean circular buttons with soft sky blue and red backgrounds for adjusting, rotating 90°, and removing pages.
- **Custom Document Naming**: Easily set any PDF name (defaults cleanly to `Untitled.pdf` if left blank).
- **Auto-Adjusting Layout & Fluid Grids**: Fully responsive across mobile, tablet, and desktop displays.
- **Exact Margins**: Choose from 0 mm, 5 mm, 10 mm, 15 mm, or 20 mm.
- **Private & Offline**: 100% client-side conversion in your browser with zero server uploads.

## Launch
Double-click [`launch_app.bat`](./launch_app.bat) or open [`index.html`](./index.html) in any modern web browser.
